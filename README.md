# iStream - Official Android Movie & TV Series App

The official Android application for **iStream Cinema**, featuring the Reezn mobile layout, hardware-accelerated video playback, ad-free streaming, and full touch responsiveness.

## Features
- **Reezn Mobile UI**: Adaptive vertical posters and dedicated mobile bottom navigation.
- **Hardware Acceleration**: Smooth 4K and 1080p video rendering with auto-orientation player.
- **Auto-Next & Smart Resumption**: Seamless binge-watching with season/episode selector.
- **My List & Watch History**: Offline caching of saved titles and watch progress.
